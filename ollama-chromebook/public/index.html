Cost and privacy guardrails

This uses GitHub Codespaces' included monthly allowance, not unlimited free compute. Keep the Codespace on the included 2-core machine, leave the forwarded port private, and stop the Codespace when finished. No Ollama Cloud account, API key, external tunnel, or public port is used.

Qwen 0.5B is a small model, not a frontier AI. Replies may be slow on CPU and it can make mistakes. Do not use it for sensitive information or important decisions.
